# Exercícios PHP — BI

Projetos de exercícios em PHP, cada um em sua pasta.

- `cadastro_produtos/` — cadastro de produtos (PHP + MySQL). Veja `database.sql` e `README.md`.
- `portal_aluno/` — portal do aluno, com cadastro, login e resultado. Veja `README.md` e `TESTES.md`.
- `exercicios_php/` — exercícios de PHP: cadastro de aluno, calculadora de média, inscrição em evento e simulador de pedido.

As configurações de banco usam variáveis de ambiente (`DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`), com padrões do XAMPP local.
